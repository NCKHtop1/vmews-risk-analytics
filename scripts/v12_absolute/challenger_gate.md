# V12.1 Challenger Gate

V12.1 is accepted only if:

- MAE improves against V12 baseline.
- Improvement survives chronological OOS evaluation.
- No degradation in calibration coverage.
- No sealed-label tuning.
- Stability is checked across market regimes.

The objective is not bigger forecast numbers. The objective is lower forecast error.

Examples:

Bad:

35.00 -> 35.80 because the number looks more predictive.

Good:

35.00 -> 35.12 because market, sector and alpha evidence support it and OOS MAE improves.
