# Financial Report Generator

Module integrated into vmews-risk-analytics.

## Features
- Select ticker
- Select financial statement period
- Export Excel format similar to MBB_2020_2025.xlsx
- VNStock data connector ready
- Validate available periods per ticker
- Extendable fallback data normalization layer

## Structure

financial-report/
- frontend: web interface
- backend: data engine
- templates: Excel templates
