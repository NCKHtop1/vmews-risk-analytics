RESEARCH OBJECTIVE

What the system measures

  • Which listed securities show material deterioration at date T.
  • Whether independent single-name models support the same warning.
  • For liquid HOSE names, whether a pooled market-specific model ranks the state toward historically higher 20-session drawdown risk.
  • Whether ranking, absolute probability and standalone-alert evidence each pass their own validation gate.
0–100 structural scores are risk indices. The pooled HOSE risk percentile is a separate predictive-evidence layer. Absolute pooled probability is withheld when calibration stability fails, and the pooled model cannot create RED/YELLOW while its standalone alert gate is not approved.

MODEL GOVERNANCE

Research controls

  • Canonical policy VMEWS-ALERT-POLICY-4.0.0 defines WATCH 50 / YELLOW 65 / RED 78 across the market scan, detail labels, watchlist and chart.
  • Market-wide RED/YELLOW requires current EOD data, liquidity, weak trend and multiple independent stress signals; a drawdown alone cannot force RED.
  • The current model state is the latest completed feature date. It is deliberately not treated as a labelled training example; forward labels end at least 20 sessions earlier.
  • Primary event: 20-session forward drawdown ≤ -12%.
  • Chronological model-fit, calibration and test windows are separated by a 20-session-equivalent purge; no random train/test split.
  • The pooled HOSE candidate is selected on development folds and evaluated on a sealed last-period block; post-freeze robustness diagnostics can only downgrade evidence.
  • Pooled ranking must survive both time-block and security-cluster resampling plus sealed sub-period discrimination checks.
  • Absolute pooled probability is displayed only when calibration is stable in the full sealed block and each sealed sub-period. The current pooled model withholds absolute probability because this stability gate is not satisfied.
  • The pooled standalone alert gate is separate. The current pooled model cannot create RED/YELLOW or an autonomous action.
  • Risk-bucket event rates are empirical sealed historical frequencies, not point forecasts for the current security.
  • VNINDEX evidence is excluded rather than imputed neutral when unavailable.
  • Raw prices remain visible on the investor chart. Large one-day discontinuities are neutralized only inside research returns/labels and disclosed as corporate-action suspects.
  • Champion retraining/promotion is manual; daily runs perform frozen-model inference only.
MODEL SET

Independent research components

  • Whole-market T-day structural deterioration screen.
  • Deterministic structural EWS and historical analogs.
  • Single-name regime clustering, seeded Random Forest and adaptive neuro-fuzzy inference.
  • Seeded VAE anomaly model and seeded LSTM crash/rebound classifiers.
  • Pooled HOSE champion: market-specific cross-sectional logistic classifier selected against a shallow boosted-tree challenger using development evidence, then evaluated on a sealed block and robustness-audited.
  • Full-universe headline NLP with relevance, source quality, event taxonomy, deduplication and time decay.
  • Chronological calibration, model ablation, robust pooled ranking and explicit uncertainty withholding.
