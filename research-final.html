MODEL GOVERNANCE

Research controls

  • 20-session crash event: forward drawdown ≤ -12%.
  • 20-session rebound event: forward gain ≥ +12%.
  • Chronological folds with a 20-session-equivalent purge; no random train/test split.
  • VNINDEX uses an independent EOD context snapshot with multiple ticker fallbacks; unavailable market context is excluded, never treated as normal risk.
  • Corporate-action suspects are flagged and one-day discontinuities above the HOSE research guard are neutralized in model returns and event labels.
  • Current context overlay is separated from historically validated model scores.
  • Bank fundamental context excludes generic debt/equity and net-margin penalties; missing NPL, CAR and NIM vintages are disclosed rather than imputed.
MODEL SET

Independent research components

  • Deterministic structural EWS.
  • Historical state matching and regime clustering.
  • Random Forest nonlinear benchmark.
  • Adaptive neuro-fuzzy inference (ANFIS).
  • Variational autoencoder latent anomaly score.
  • LSTM dual crash/rebound sequence classifier.
  • Hashed unigram/bigram logistic NLP baseline with financial seed labels, event taxonomy and time decay.
