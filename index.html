02 · MODEL LAB

Research model, clearly separated from the live demo layer

The thesis combines ANFIS for nonlinear early-warning prediction with VAE/LSTM-style anomaly detection. This portfolio preserves that architecture and reports the thesis benchmarks exactly as written.

Reproducibility disclosure

The PDF provides the model equations, architecture and reported results, but not the original 745,452-row raw dataset, trained weight files, complete MATLAB project, or every tuned hyperparameter. Therefore an exact byte-for-byte reproduction of the original trained model is not possible from the PDF alone. The repository includes a faithful, runnable reference implementation and labels any live proxy output clearly.

05 · DATA & METHODOLOGY

Built for scrutiny, not just screenshots

The portfolio separates research claims, current market data, implementation assumptions and operational controls so a reviewer can see exactly what is original, what is reproduced and what is newly engineered.

01

Crash definition

Weekly specific return is transformed as Rw = ln(1 + ew). A crash is flagged when Rw < μR − 3.09σR, following the thesis COUNT/CRASH approach.

02

Research split

The thesis states 80% train, 10% validation and 10% test, with walk-forward retraining. The PDF contains an ambiguous date sentence for validation/test; the repository preserves the text and does not invent a corrected date.

03

Live data

The deployed API requests the latest VN-Index daily OHLC series. If the upstream feed is unavailable, the UI falls back to an embedded verified snapshot and visibly marks the data as fallback.

04

Data controls

Nulls, duplicate timestamps, non-positive prices, ordering, freshness and source mode are checked before risk metrics are calculated.

05

Model governance

Research benchmark metrics are immutable reference values. Live proxy logic is versioned separately so it cannot be mistaken for the original trained ANFIS/VAE output.

06

Deployment

Static frontend + serverless market-data endpoint. No client-side secrets. Cache headers reduce upstream requests while keeping daily market data fresh.
